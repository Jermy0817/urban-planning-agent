# Planning Agent 1.0

面向编程初学者的本地策划辅助工作台。这是可运行的规则型最小版本，不是能独立完成策划的自主智能体。无需 API 密钥。

## GitHub 与云端部署

公开仓库仅包含程序源码，不包含个人项目资料、生成报告或虚拟环境。GitHub 托管代码本身不会运行 Python 应用。

如使用 Streamlit Community Cloud，选择此仓库、main 分支、入口 app.py 和 Python 3.12。依赖由 requirements.txt 安装。

云端运行时，上传文件会发送到托管服务器处理，并非仅留在使用者电脑。公开演示只使用虚构或脱敏资料；敏感项目继续使用本地版本。本版本未实现访问控制，不应作为敏感资料的公开处理服务。

## 架构与实施顺序

浏览器界面（Streamlit，仅本机）→ 文件解析（pypdf / python-docx / openpyxl）→ 带出处文本片段 → 规则事实提取 → 关键词经验检索 → 建议模板与人工审核 → Markdown 下载。

1. 第一阶段（本版本）：建立事实与证据链，手工选取公开来源，提供规则草稿。
2. 第二阶段：在真实项目上逐项标注正确答案，测量遗漏与误提取；补 OCR、复杂表格和单位/口径识别。优先保证可靠性。
3. 第三阶段：为个人经验增加地区、时间、项目类型、效果与教训等字段，再考虑本地全文索引或向量检索。
4. 第四阶段：可选接入本地模型，或在明确授权与脱敏后调用云模型；设置费用上限、每次发送预览、来源约束。模型输出仍须审核。
5. 第五阶段：再接搜索 API、来源归档、政策版本与审核记录。不要一开始构建多 Agent、自动支付或自动发布。

## Windows 启动

在本文件所在文件夹打开 PowerShell，首次安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

之后每次启动：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false --server.maxUploadSize 25
```

浏览器访问 http://127.0.0.1:8501 。终端按 Ctrl+C 停止。不要开放到公网。

无需依赖即可演示核心流程：`python demo.py`，输出在 output/示例策划初稿.md。示例是虚构数据。

## 使用流程

1. 左侧上传任务书，右侧上传自己的项目复盘或已核实资料；同名文件请先改成唯一名称。
2. 输入经验关键词；检查事实候选与完整提取文本。引用位置为 PDF 页、Word 正文段落/表行、Excel 工作表/单元格、TXT 行。
3. 用独立的公开关键词搜索政策、案例、数据。只在点击链接后访问搜索服务，不会自动携带上传文件内容。手动下载选定资料并记录来源信息，再导入。
4. 修改草稿，下载 Markdown，用文本编辑器即可打开。逐项完成审核清单，另存人工批准版本。

## 边界与成本

- 无收费模型或搜索 API 调用；安装依赖和打开搜索网页需要联网，网络/电脑及人工成本另计。
- 面积、金额是候选值，不自动合计、换算或区分用地/建筑面积、总投资/分项金额；冲突会保留供核对。中文数字、跨行单位和复杂表格可能遗漏。
- PDF 扫描件不会自动 OCR。Word 不读取图片、文本框、页眉页脚及嵌套表格；XLSX 只读单元格，不执行宏或公式，也不获取外部链接。旧 DOC/XLS 请先转换。
- 关键词检索仅提供相关片段，不理解完整项目；建议来自固定规则和引用片段，没有模型推理。公开搜索目前为辅助入口，不是自动采集或政策核验。
- 文件暂存于系统临时目录，解析后清除；上传内容仍可能存在于进程内存，关停程序释放。下载的报告由你保管；临时文件删除不等于安全擦除。
- 只处理可信文件。25 MB 限制不等于恶意文件隔离；压缩炸弹、损坏文件和超大页数仍可能消耗资源。不要作为对外文件处理服务。
- 不执行文档中的指令，不运行附件程序；本版本没有工具执行代理。未来接入模型时应把文档视为不可信证据，不允许其改变权限或发送资料。
- 未实现用户权限、加密存储、审核签名或生产级审计。敏感项目请使用受控本机及加密磁盘，避免将目录同步到公共云盘。

## 经验资料模板

每个项目建立一个 TXT/MD：项目名称（可脱敏）、地区、年份、类型、面积口径、投资口径、建设内容、运营主体、实际效果、失败教训、适用条件、原始证据位置。把事实与个人判断分开写。
